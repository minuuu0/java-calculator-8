## 문자열 덧셈 계산기 기능 목록

### ✅ 1. 유효한 요청 처리

#### 1-1. 기본 동작

- [x] 빈 문자열 입력 시 `0` 반환
- [x] 숫자 하나 입력 시 해당 숫자 반환

#### 1-2. 기본 구분자

- [x] 쉼표(`,`)를 구분자로 사용하여 합 반환
- [x] 콜론(`:`)을 구분자로 사용하여 합 반환
- [x] 쉼표와 콜론을 함께 사용하여 합 반환

#### 1-3. 커스텀 구분자

- [x] 일반 문자를 커스텀 구분자로 사용 (예: `//;\n1;2;3` => `6`)
- [x] 숫자를 커스텀 구분자로 사용 (예: `//7\n172737` => `6`)
- [ ] `.`을 커스텀 구분자로 사용 (정수만, 예: `//.\n1.2.3` => `6`)

#### 1-4. 특수 케이스

- [ ] 연속된 구분자를 `0`으로 처리 (예: `1,,3` => `4`)
- [ ] 소수(실수) 포함 합 계산 (예: `1.5,2.3` => `3.8`)
- [ ] 자연수와 소수 혼합 (예: `1,2.5,3` => `6.5`)

---

### ❌ 2. 예외 처리

#### 2-1. 커스텀 구분자 형식 오류

- [ ] `//`로 시작하지만 `\n`이 없는 경우
- [ ] `//`와 `\n` 사이에 구분자가 없는 경우
- [ ] `//`와 `\n` 사이에 구분자가 2개 이상인 경우

#### 2-2. 숫자 값 오류

- [ ] 음수 입력
- [ ] `0` 명시적 입력
- [ ] 숫자 자리에 문자 입력
- [ ] 구분자만 있고 숫자 없음 (예: `//;\n`)
- [ ] 커스텀 구분자 `.` + 소수 충돌 (예: `//.\n1.5.2.3`)

#### 2-3. 범위 초과 오류

- [ ] 입력값이 `double` 범위 초과
- [ ] 계산 결과가 `double` 범위 초과
